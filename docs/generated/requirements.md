# System Requirements Matrix

| ID | Status | Priority | Statement | Acceptance Criteria |
|---|---|---|---|---|
| **CDAL-REQ-ADAPTER-AGENTS** | `DONE` | HIGH | System must generate AGENTS.md and .cursor/rules/cdal.mdc for non-Claude runtimes. | 1. Updates managed section with phase gate guidelines<br>2. Generates valid Cursor rule MDC files |
| **CDAL-REQ-ADAPTER-ANTIGRAVITY** | `DONE` | HIGH | System must generate .agents/ workspace files respecting the 12,000 character limit per rule file. | 1. Maps Claude tools to Antigravity tools<br>2. Splits rules files exceeding 12,000 characters |
| **CDAL-REQ-ADAPTER-CLAUDE** | `DONE` | HIGH | System must generate .claude/settings.json, agent roles, commands, and CLAUDE.md with managed markers. | 1. Preserves custom user text outside managed markers<br>2. Wires PreToolUse hooks to cdal hook<br>3. Settings and role frontmatter follow the Claude Code hooks schema (matcher groups with typed command handlers) |
| **CDAL-REQ-AUDIT-DRIFT** | `DONE` | MEDIUM | Audit engine must detect untracked or manual edits to generated contract artifacts. | 1. Heuristic inspection of files with GENERATED banners<br>2. Flags drift without requiring external tools |
| **CDAL-REQ-AUDIT-OFFLINE** | `DONE` | HIGH | cdal audit must scan repositories offline for type silencing, skipped tests, and self-grading. | 1. Operates without internet connection<br>2. Evaluates codebase health score 0-100 |
| **CDAL-REQ-AUDIT-REPORT** | `DONE` | MEDIUM | cdal audit must generate a single-file offline HTML report with dark mode and action items. | 1. Zero external assets or CDN dependencies in HTML<br>2. Includes actionable remediation guidance |
| **CDAL-REQ-CODEGEN** | `DONE` | HIGH | cdal codegen must emit TypeScript types and Markdown documentation with drift detection. | 1. Identical outputs across consecutive runs<br>2. --check exits with code 1 upon file drift |
| **CDAL-REQ-CONFIG** | `DONE` | CRITICAL | System must load and validate cdal.config.mjs with strict type-safety and presets. | 1. Invalid config throws CdalConfigError<br>2. Presets merge forbidden and protected paths |
| **CDAL-REQ-DOCTOR** | `DONE` | MEDIUM | cdal doctor must inspect Node version, git state, hook wiring, and configuration health. | 1. Requires Node >= 20.9.0 LTS<br>2. Detects un-hooked environments and drifted files |
| **CDAL-REQ-GATE-EVASION** | `DONE` | CRITICAL | Guard system must detect obfuscation patterns such as identifier splitting and dynamic eval. | 1. Blocks split string literals joined by empty separator<br>2. Intercepts evasive regex and dynamic execution |
| **CDAL-REQ-GUARD-BASH** | `DONE` | CRITICAL | guard-bash must intercept dangerous shell executions including package publishing and raw deployment. | 1. Direct npm publish or vercel deploy is blocked<br>2. Forbidden bash patterns trigger exit 2 |
| **CDAL-REQ-GUARD-FORBIDDEN** | `DONE` | HIGH | guard-forbidden must block compiler silencing (@ts-ignore, as any) and skipped tests. | 1. Matching patterns trigger exit code 2 with remedial message<br>2. allowIn paths are exempt |
| **CDAL-REQ-GUARD-PATH** | `DONE` | CRITICAL | guard-paths must enforce per-role write scopes and physically block implementers from test edits. | 1. Implementer role is denied editing test files (denyTests: true)<br>2. Unauthorized paths return exit 2<br>3. A role declared by a CDAL role hook but missing from cdal.config.mjs is denied every write (fail closed); sessions and built-in subagents without a declared role are only checked against protected paths |
| **CDAL-REQ-HOOK-ROUTER** | `DONE` | HIGH | cdal hook router must process tool payloads from Claude Code and Antigravity within 150ms SLA. | 1. P95 latency under 150ms benchmark in CI<br>2. Supports stdin payload reading and exit 2 blocking |
| **CDAL-REQ-INIT** | `DONE` | HIGH | cdal init must scaffold contracts, config, and runtime files for new or existing projects. | 1. Adds verify scripts to package.json<br>2. Preserves existing user configurations |
| **CDAL-REQ-KIND-POLICIES** | `DONE` | HIGH | Standard policies kind must validate numeric thresholds, scopes, units, and ascending bands. | 1. Bands must be strictly ordered<br>2. Missing scopes or units trigger findings |
| **CDAL-REQ-KIND-REQUIREMENTS** | `DONE` | HIGH | Standard requirements kind must enforce unique IDs, valid statuses, and parent relationships. | 1. Detects duplicate requirement IDs<br>2. Validates status transitions |
| **CDAL-REQ-KIND-STATE-MACHINE** | `DONE` | HIGH | Standard state machine kind must verify reachability, no dead-ends, and deterministic transitions. | 1. Validates state reachability via BFS<br>2. Flags dead-end non-terminal states |
| **CDAL-REQ-KINDS** | `DONE` | HIGH | System must support modular contract kinds with invariant rules, codegen, and selftest mutations. | 1. Custom contract kinds can register rules<br>2. Cross-kind context is accessible during validation<br>3. cdal validate and cdal codegen use the kinds registered in cdal.config.mjs (built-in kinds only when none are configured) |
| **CDAL-REQ-PHASE** | `DONE` | CRITICAL | cdal phase must enforce file boundaries based on git diffs for RED, GREEN, and CONTRACT phases. | 1. RED phase accepts only test modifications<br>2. GREEN phase rejects test changes if production changed |
| **CDAL-REQ-PRO-INSTALL** | `DONE` | HIGH | CLI must install CDAL Pro content into a project from the private cdal-pro repository or a local copy, driven by the pro.manifest.json shipped with that content. | 1. Copies every manifest mapping into the project and records the installed version in .cdal/pro.json<br>2. Never overwrites user-owned files unless --force is passed (files generated by cdalkit sync are replaced); --dry-run writes nothing<br>3. Rejects manifest paths that are absolute or escape the source or project directory |
| **CDAL-REQ-SELFTEST** | `DONE` | CRITICAL | cdal selftest must prove quality gates fail when broken by running contract mutations. | 1. Every invariant rule has at least one positive mutation probe<br>2. Fails if any rule cannot be broken |
| **CDAL-REQ-SYNC** | `DONE` | HIGH | cdal sync must regenerate adapter files and detect configuration drift via --check. | 1. --check exits 1 upon file drift<br>2. Synchronizes all configured target runtimes<br>3. Files marked <!-- cdal:preserve --> are user-owned: never overwritten or reported as drift |
| **CDAL-REQ-TRACE** | `DONE` | CRITICAL | cdal trace must map every requirement ID to tagged tests (@REQ:) and enforce 100% coverage. | 1. Scans @REQ annotations in test files<br>2. --enforce fails if active requirements lack tests |
| **CDAL-REQ-VALIDATE** | `DONE` | CRITICAL | cdal validate must evaluate contract rules and output findings in text and JSON formats. | 1. Exits 0 on valid contracts<br>2. Exits 1 and outputs structured findings on invariant violations |
| **CDAL-REQ-VERIFY** | `DONE` | CRITICAL | cdal verify must run configured pipeline steps in sequence and return single exit status. | 1. Returns 0 only when all steps succeed<br>2. Supports --fast and --full modes |
| **CDAL-REQ-WINDOW** | `DONE` | HIGH | Protected contract files can only be modified while an explicit contract window is open. | 1. cdal window open/close manages ticket state<br>2. Writing to contracts while window is closed triggers exit 2 |
