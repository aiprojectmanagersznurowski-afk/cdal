# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of CDAL Kit and developer workspaces seriously.

If you believe you have found a security vulnerability in CDAL:
1. **Do not open a public GitHub issue.**
2. Please report vulnerabilities privately by emailing `security@cdalkit.dev` (or directly to Michal Sznurowski).
3. Include detailed steps to reproduce the issue, environment information, and proof of concept.

We commit to acknowledging your report within 48 hours and providing a remediation timeline.
