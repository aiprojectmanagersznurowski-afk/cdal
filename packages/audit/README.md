# @cdal/audit

Repository quality and AI hygiene audit engine for CDAL (100% offline, zero telemetry)

Part of [CDAL](https://cdal-henna.vercel.app) (Contract-Driven Agentic Loop): quality gates and auditability for AI-written code. Most projects use it through the CLI:

```bash
npx cdalkit audit
```

Documentation: https://cdal-henna.vercel.app/docs
